# Yuchen Panel 产品定义

## 一句话定位

Yuchen Panel 是一套面向跨境业务、外贸团队、海外社媒运营、AI 工具使用团队和服务器服务商的开源服务器节点管理面板。

## 目标用户

1. 普通技术用户：自用单机面板。
2. 小团队：管理自己的服务器、节点和员工设备。
3. 服务器服务商：为客户交付可视化管理面板。
4. 跨境技术服务商：提供部署、维护、故障排查和长期升级服务。
5. 企业私有化客户：需要多服务器总控、客户后台、权限隔离和审计日志。

## 客户端支持约定

订阅提供 Clash/Mihomo YAML、通用 v2rayN/Shadowrocket base64，以及 sing-box 现代 JSON。
最低支持 **sing-box ≥1.12.0**；1.13.0 及以上必须使用现代 DNS，旧格式可能 FATAL，1.14 已移除旧格式。
如你的 sing-box ≥1.13，请勿手工编辑导出的 DNS 段。不提供 legacy 导出。
桌面默认 mixed 入站 127.0.0.1:2080；手机 VPN 或桌面 TUN 使用可选 `profile=tun`，运行时需 VPN/管理员权限。
具体客户端矩阵、自动下载脚本及待执行的设备验收见 [CLIENT-COMPAT.md](CLIENT-COMPAT.md)。
当前设备与真实节点连通测试为 MANUAL_REQUIRED；流量配额仅展示，未实施强制限额。

## 节点性能与抗识别档位

本部署的用户已确认客户主要在墙内、需要抗封锁，因此新建 VLESS 默认为**抗封锁档**，而不是按“海外 VPS 吞吐优先”假设选择极速档。已设为 Reality 或 none 的存量节点不会被改写；Trojan 默认 TLS，VMess 默认 none。

| 档位 | 参数 | 性能与抗识别取舍 |
| --- | --- | --- |
| 极速 | VLESS / TCP / none | 无额外传输层加密；抗识别低。吞吐未实测，不能承诺比 Reality 更快。适合无需抗封锁、吞吐优先的线路。 |
| 均衡 | VLESS / gRPC / none | HTTP2 封装，性能影响未实测；抗识别中只是相对裸 TCP 的定性标签，并非 TLS 保护或抗封锁保证。 |
| 抗封锁（本部署默认） | VLESS / TCP / Reality | TLS 外观与加密，抗识别较高；性能影响未实测，不能保证免封锁。适合主要墙内的客户。 |

高级入口保留 WS、gRPC、TCP 和可用安全方式的直接选择。点击高级仅展开字段，不自动重写协议；只有显式选择某一 VLESS 档位时才应用对应参数。Reality 保存前自动生成密钥。

服务器规格来自现有 Agent 心跳，在原 `/api/system/checks` 返回按 server ID 区分的规格。≤ 2 个可用逻辑核时提示吞吐优先可考虑极速档，≥ 4 核时提示可用 Reality，低于 1 GiB 内存时提醒 OOM 风险。这些只是建议，不会覆盖墙内客户的默认档位。旧 Agent 或规格读取失败时静默隐藏相应提示，不能用 CPU/内存使用率推断容量，也不能把面板容器规格当成远程节点规格。

线路延迟、丢包和出口拥塞可能限制吞吐。核数、档位和加密开销的定性描述都不能证明单连接速度；本轮没有编造百分比或把协调者的一次 A/B 延迟结果推广为带宽结论。
